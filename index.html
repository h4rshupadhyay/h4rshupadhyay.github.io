Inside TradePulse +

A system-of-record backend for the NevUp AI Trading Coach. It stores closed trades and exposes sessions, trader profiles, and behavioral metrics through authenticated REST APIs.

PostgreSQL stores the trade records; Redis Streams sends events to a separate worker. The worker computes plan adherence, revenge-trading flags, session tilt, win rate by emotion, and overtrading metrics. These calculations are deterministic and run outside the write path.

Parameterized SQL, idempotent inserts, and JWT checks at the path, body, and resource levels protect correctness and tenant isolation. Structured request logs and a health endpoint expose database status and queue lag.

The repository reports a 60-second k6 run at 200 requests per second with 4.19 ms p95 write latency, 8.48 ms p95 read latency, and zero errors. It documents 151 integration tests against the Docker stack.

Stack: Node.js 20, Express.js, PostgreSQL 16, Redis 7 Streams, Docker Compose, JWT, pino, and k6.

Inside PaperTrade +

A Database Systems Lab project for practicing stock trading with virtual funds and Yahoo Finance market data. It combines an Oracle database, a Flask API, and a React interface.

Users can place market, limit, stop, and stop-limit orders; organize watchlists into folders; set price alerts; and keep ticker-linked trading notes. Portfolio views include growth history, sector allocation, holdings, and profit-and-loss analysis, with display support for USD, INR, GBP, EUR, JPY, and HKD.

The normalized Oracle schema includes an immutable transaction ledger. PL/SQL triggers check available cash, prevent overselling, update balances, and recalculate holdings using volume-weighted cost basis. JWT sessions and bcrypt password hashing support authentication.

Background services refresh active prices, evaluate pending orders and alerts, and save portfolio snapshots. A thread-safe cache reduces duplicate market-data requests; idempotent schema migrations run when the backend starts.

Stack: Oracle 21c XE, SQL and PL/SQL, Python 3.12, Flask, React 18, Vite, Recharts, yfinance, and Docker Compose.
